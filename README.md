# 杂交育种 Crossbreeding

把孟德尔遗传学搬进 Minecraft 的小麦育种模组。

---

## 快速上手

1. **打草** → 25% 概率额外掉落杂交种子（原版种子照常掉）
2. **种地** → 像原版小麦一样种在耕地上
3. **看表型** → 手持**石锄**右键成熟小麦
4. **收获** → 破坏成熟小麦，掉落杂交小麦 + 2~3 个配子
5. **杂交** → 1 雌配子 + 1 雄配子放工作台 → 新种子
6. **做面包** → 用杂交小麦合成，品质由基因决定

> **注意**：原版小麦和原版种子**不受影响**，只有打草和杂交作物会产出杂交物。

---

## 遗传学基础

每株小麦有 **6 对基因**，共 12 字符，如 `AaBbccDdEeFF`。

- **大写** = 显性，**小写** = 隐性
- 一对基因**有一个大写**即表现显性
- **两个小写**才表现隐性

### 基因对照表

| 基因对 | 显性（大写） | 隐性（小写） |
|--------|-------------|-------------|
| A / a | **多穗** | 少穗 |
| B / b | **抗病** | 不抗病 |
| C / c | 低饱食 | **高饱食** |
| D / d | 低饱和 | **高饱和** |
| E / e | 多壳 | **少壳** |
| F / f | **生长旺盛** | 生长不旺盛 |

> 加粗是"好性状"。A、B、F 好性状在**显性**上，C、D、E 好性状在**隐性**上。

---

## 六个性状效果

| 性状 | 效果 |
|------|------|
| 多穗（A_） | 额外掉 2~3 个杂交小麦 |
| 少穗（aa） | 无额外掉落 |
| 抗病（B_） | 生长中不会染病 |
| 不抗病（bb） | 生长时有 1/2 概率枯萎 |
| 高饱食（cc） | 面包额外 +2 饥饿值 |
| 高饱和（dd） | 面包额外 +2 饱和度 |
| 少壳（ee） | 1 个小麦做 1 个面包 |
| 多壳（E_） | 3 个小麦做 1 个面包 |
| 生长旺盛（F_） | 生长速度翻倍 |

---

## 面包合成

要求**全部小麦**都满足对应性状，否则合成普通面包。

| 条件 | 数量 | 产出 |
|------|------|------|
| 全部 `ee` + `cc` + `dd` | 1 或 3 | 高饱食高饱和面包 |
| 全部 `cc` | 1 或 3 | 高饱食面包 |
| 全部 `dd` | 1 或 3 | 高饱和面包 |
| 其他 | 1 或 3 | 杂交面包 |

数量由**第一个小麦**决定：少壳（ee）用 1 个，多壳（E_）用 3 个。

## 石锄查看表型

手持石锄右键成熟小麦，聊天框显示：

```

位于（10，64，20）的小麦
表型：多穗、抗病、高饱食、高饱和、多壳、生长旺盛

```

点击这段消息可以**复制到剪贴板**（简单模式下会连基因型一起复制）。

---

## 简单模式

需要 OP 等级 ≥ 2：

```

/crossbreeding simple true    开启
/crossbreeding simple false   关闭

```

开启后：

- 石锄右键时额外显示基因型
- 配子、种子、小麦的悬停提示显示基因型
- 点击复制时连基因型一起复制

状态保存在存档里。

---

## 基因调试棒（创造模式专用）

**获取方式**：创造模式物品栏"管理员用品"页面，或 `/give @s crossbreeding:gene_debug_stick`。

**用法**：

1. 手持调试棒
2. **左键**：循环切换基因位点 `Aa → Bb → Cc → Dd → Ee → Ff → Aa`
3. **右键**杂交小麦：循环切换该位点的基因型 `AA → Aa → aa`

屏幕下方会短暂显示当前状态。
